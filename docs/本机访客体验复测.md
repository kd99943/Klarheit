# Klarheit 本机访客体验复测

2026-11-23，在运行中的 `http://localhost:3000` 使用独立的 Chrome 访客会话体验。桌面视口为 1440 × 800，手机布局使用 390 × 844 视口模拟。走查覆盖首页、目录筛选、商品详情、3D 预览、虚拟试戴的模型模式、购物车和页脚弹窗。本次未登录、未启用真实摄像头、未下单。以下七项是上一份报告之外的浏览器复现结果，修复建议均待实施。

## 1. 高优先级 · 刷新会清空访客购物车

**复现**　以访客身份打开 MONOLITH 02，点击“加入购物车（稍后配镜）”，进入购物车。页面显示 1 副、¥620.00。停留后刷新同一个标签页，购物车变为空，导航角标也消失。此现象多次复现。

**定位与改法**　刷新时浏览器收到 `/auth/me` 的 401。`front_end/src/services/api.ts` 遇到 401 就广播 `klarheit:session-expired`，`auth/AuthProvider.tsx` 和 `hooks/useCart.tsx` 会据此清理本地状态。区分“启动时发现当前是访客”和“已有账户的会话失效”，只有后者触发对应的账户清理。保留退出和切换账户时对处方及试戴数据的隔离。

**验收**　新访客加购后刷新两次，款名、数量、尺码和金额保持一致。另测已登录账户退出、会话过期和切换账号，确认前一账户的购物车与私人草稿不会出现在下一账户。

## 2. 中优先级 · 首页底部进入商品系列后，落在列表中段

**复现**　在桌面首页滚到最下方，用底部的商品系列入口进入目录。待四款商品加载完成，窗口的纵向滚动位置仍为 655px，目录主标题顶边位于视口上方 475px。首次进入的访客会错过目录标题和筛选区的开头。

**改法与验收**　在普通页面前进导航时回到页首。保留 `CollectionsPage.tsx` 已有的“从详情返回原商品卡片”行为。分别从首页底部进入目录、从目录进入详情再返回，前者应看见主标题，后者应回到刚浏览的卡片。

## 3. 中优先级 · 所有配色均缺货，详情页却提示其他色款可购

**复现**　在中文目录打开 AERO X1。哑光黑、玫瑰金、钛金属三个选项都标有“缺货”，当前钛金属下方仍显示“其他色款仍可正常选购”。商品页底部同时提示当前款无法下单。

**改法与验收**　在 `ProductDetailsPage.tsx` 选择提示语前，使用实际 SKU 可售性检查是否有可购买的其他配色。全部缺货时显示“该款所有配色暂时缺货”，并给出返回目录的入口。用“部分色款有货”和“所有色款缺货”两组数据分别验收。

## 4. 中优先级 · 手机菜单收起后仍可通过键盘进入隐藏链接

**复现**　在 390px 宽的首页，将键盘焦点移到菜单按钮。菜单保持收起，按 Tab 后焦点进入透明菜单里的“产品系列”，按 Enter 即跳往目录。实测此时按钮的 `aria-expanded` 为 `false`，菜单透明度为 0。

**改法与验收**　`Navbar.tsx` 的 `#mobile-navigation` 通过透明度和指针事件隐藏。给收起状态加 `inert`，或在关闭后卸载菜单。关闭时连续按 Tab 应经过可见控件，打开后应能依次访问菜单项，收起时焦点回到菜单按钮。

## 5. 中优先级 · 客服弹窗打开后，Tab 移到遮罩后方

**复现**　在首页页脚打开“客服与服务规则”。弹窗显示后，焦点仍在背景的触发按钮；按一次 Tab，焦点移到背景里的“隐私与数据权利”。键盘用户无法从当前位置直接操作眼前的弹窗。

**改法与验收**　调整 `Footer.tsx`：弹窗打开时聚焦关闭按钮，打开期间将焦点限制在弹窗内，关闭后恢复到触发按钮。客服和隐私弹窗各测一次 Tab、Shift+Tab 和 Escape。

## 6. 较低优先级 · 价格上下限填反时，页面只显示无商品

**复现**　在中文目录输入最低 ¥900、最高 ¥600。页面接受这两个筛选条件，显示 0 款和“未找到符合筛选条件的商品”。这个结果无法告诉用户应修正哪个输入框。

**改法与验收**　在 `CollectionsPage.tsx` 检查两端均有值且最低价高于最高价的情况，在输入框附近显示“最低价不能高于最高价”，暂停此次查询。将最高价改为 ¥950 后应立即恢复筛选；只填单边价格应继续可用。

## 7. 较低优先级 · 中文浏览器首次进入显示英文，页面语言标记却是中文

**复现**　以没有站点偏好记录的浏览器会话打开首页。浏览器首选语言为 `zh-CN`，页面标题、导航和主要按钮的正文为英文，HTML 语言标记为 `zh-CN`。点击“中”后正文才改为中文。

**改法与验收**　`i18n/index.ts` 对首次访问固定回退到英文。如果产品希望跟随浏览器语言，按“用户已保存的选择 → 浏览器支持的语言 → 默认语言”初始化。无论默认语言如何选择，都应在初始化和切换时同步 `document.documentElement.lang`。用中英文浏览器各开一次新会话，再手动切换、刷新，核对正文、语言标记与已保存偏好一致。
